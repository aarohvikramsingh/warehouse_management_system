# Warehouse Management System

A local desktop application built with Java Swing. Product, inventory, and supplier data lives only in memory and resets when the application closes.

## Run in VS Code

1. Install JDK 17 or newer and the **Extension Pack for Java** in VS Code.
2. Open this folder in VS Code.
3. Open `src/main/java/edu/college/wms/Main.java` and click **Run** above `main`.

You can also compile the application with `javac --release 17` or use `mvn compile exec:java` if Maven is installed.
